## Original assets and factual references

The published `@react-three/fiber` package omits a root license file. Its notice was retrieved from the official source repository at release gitHead `e53d667aa0326024be2772558a7a593e2bb825d3` (the npm metadata for version 9.3.0): https://raw.githubusercontent.com/pmndrs/react-three-fiber/e53d667aa0326024be2772558a7a593e2bb825d3/LICENSE .

The geometry is an educational generic four-way caliper, informed by the manufacturer sources listed in SOURCES.md. It is not a certified replica. Historical reconstructions are original vector illustrations. The bundled source notes distinguish Nunes’s nonius from Vernier’s later construction. All generated assets have their reproduction scripts in assets/generation.
